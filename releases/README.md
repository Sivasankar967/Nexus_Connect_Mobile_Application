## Install on Android (for reviewers)

1. Copy `NexusConnect.apk` to the Android phone (USB, WhatsApp, Google Drive, or email).
2. Open the file with **Files** or **Chrome**.
3. Tap **Install**. If prompted, allow **Install unknown apps** for that app.
4. Open **NexusConnect**.
5. Sign in:
   - **Email:** `employee@nexus.com`
   - **Password:** `nexus123`  
   Or tap **Demo credentials — tap to fill** on the login screen.
